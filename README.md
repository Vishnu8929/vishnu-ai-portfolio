# Vishnu Bhargav Kotte — AI/ML Portfolio

A responsive, recruiter-friendly personal portfolio built as a lightweight static site.

## Run locally

Open `index.html` directly, or from the folder run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

### GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder.
3. In **Settings → Pages**, deploy from the `main` branch / root.

### Netlify / Vercel
Drag this folder into Netlify Drop, or import the repo into Vercel. No build command is required.

## Personalize next
